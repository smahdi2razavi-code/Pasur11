# رفع خطای «نام بستهٔ فایل APK با نام بستهٔ این برنامه مطابقت ندارد»

## این خطا یعنی چه؟

**ربطی به کلید و امضا ندارد.** مایکت می‌گوید:

> نام بسته‌ای (package name) که داخل فایل APK است، با نام بسته‌ای که موقع
> ساختن این برنامه در پنل مایکت ثبت کردی یکی نیست.

هر برنامهٔ اندروید یک شناسهٔ یکتا دارد، مثل `com.smahdi2razavi.pasur11`.
مایکت این شناسه را موقع ساخت برنامه از تو گرفته و **قابل تغییر نیست**.
پس باید APK را با آن هماهنگ کنی.

## چرا این اتفاق افتاد؟

در فایل‌هایی که به تو داده شده بود، دو نام بستهٔ متفاوت وجود داشت:

| فایل | نام بسته |
|---|---|
| `MainActivity.kt` (بدون پرداخت) | `com.smahdi2razavi.pasur11` |
| `MainActivity-با-پرداخت.kt` | `com.SMRx.pasur11` |

راهنمای ساخت پروژه هم `com.smahdi2razavi.pasur11` را گفته بود. پس بسته به
اینکه کدام را استفاده کرده باشی، APK یکی از این دو نام را دارد.

---

## گام ۱ — ببین مایکت چه نامی ثبت کرده

در پنل توسعه‌دهندهٔ مایکت، صفحهٔ برنامه‌ات را باز کن. جایی نوشته
**«نام بسته»** یا **«Package name»**. یادداشتش کن. مثلاً:

```
com.smahdi2razavi.pasur11
```

## گام ۲ — ببین APK تو چه نامی دارد

در اندروید استودیو فایل **`build.gradle.kts (Module :app)`** را باز کن.
دنبال این خط بگرد:

```kotlin
defaultConfig {
    applicationId = "com.SMRx.pasur11"      ← این عدد، نام بستهٔ APK توست
    ...
}
```

## گام ۳ — هماهنگشان کن (یک خط، بدون دست‌زدن به کد)

مقدار `applicationId` را **دقیقاً** برابر همان چیزی بگذار که در مایکت دیدی:

```kotlin
defaultConfig {
    applicationId = "com.smahdi2razavi.pasur11"   // همان که در مایکت ثبت شده
    ...
}
```

بعد: `Ctrl+S` → **Sync Now** → دوباره APK امضاشده بساز → آپلود کن.

### ⚠️ مهم: `namespace` را دست نزن!

در همان فایل یک خط دیگر هم هست:

```kotlin
android {
    namespace = "com.SMRx.pasur11"    ← این را عوض نکن
```

این دو **فرق دارند** و لازم نیست یکی باشند:

| | چیست | باید با چه چیزی یکی باشد |
|---|---|---|
| `namespace` | نام بستهٔ کد داخلی | خط اول فایل‌های `.kt` |
| `applicationId` | شناسهٔ برنامه در فروشگاه | **نام بستهٔ ثبت‌شده در مایکت** |

اگر `namespace` را عوض کنی، پروژه دیگر کامپایل نمی‌شود چون با خط اول
`MainActivity.kt` (یعنی `package com.SMRx.pasur11`) نمی‌خواند.

**پس فقط `applicationId` را عوض کن. تمام.**

---

## اگر نمی‌دانی مایکت کدام را دارد

راه مطمئن: در پنل مایکت صفحهٔ برنامه را باز کن و نام بسته را بخوان.

اگر به هر دلیل نتوانستی پیدایش کنی، دو حالت دارد:

**الف) هنوز هیچ نسخه‌ای منتشر نشده و کالای درون‌برنامه‌ای هم نساخته‌ای:**
می‌توانی برنامه را در مایکت حذف کنی و دوباره با نام بستهٔ درست بسازی.

**ب) کالاهای درون‌برنامه‌ای را ساخته‌ای (مثل الان):**
❌ برنامه را حذف نکن! با حذف آن، هر شش کالای `coins_*` و `vip_*` هم پاک
می‌شوند و باید از نو بسازی. به‌جایش `applicationId` را عوض کن.

---

## بعد از رفع مشکل

- 🔑 **کلید امضا را عوض نکن.** همان `keystore` قبلی را استفاده کن؛ اگر
  کلید عوض شود، مایکت نسخهٔ جدید را قبول نمی‌کند.
- 🔢 اگر مایکت گفت «نسخه تکراری است»، در `build.gradle.kts` مقدار
  `versionCode` را یک عدد بالاتر ببر (مثلاً از `1` به `2`) و
  `versionName` را هم مثلاً `"1.0.1"` کن.
- 💳 درگاه پرداخت با تغییر `applicationId` مشکلی پیدا نمی‌کند، چون کلید
  RSA به خودِ برنامه در پنل مایکت وصل است، نه به نام بسته.

# اگر عوض کردی و باز همان خطا را داد

اینجا باید **حدس زدن را کنار بگذاری و عدد واقعی را ببینی.**

## گام ۱ — نام بستهٔ واقعیِ همان APK را بخوان

در اندروید استودیو:

**`Build`** ← **`Analyze APK...`** ← فایل `app-release.apk` را انتخاب کن

> ⚠️ **حتماً `app-release.apk` را باز کن، نه `app-debug.apk`!**
> بالای پنجره اسم فایلی که باز کرده‌ای نوشته شده — چک کن `release` باشد.
> فایل `app-debug.apk` با کلید آزمایشی اندروید استودیو امضا می‌شود و
> مایکت هیچ‌وقت قبولش نمی‌کند. آن فایل فقط برای تست روی گوشی خودت است.

بالای پنجره‌ای که باز می‌شود، دقیقاً می‌نویسد:

```
package name: com.???.pasur11
versionCode: 1   versionName: 1.0
```

**این عدد، حقیقتِ فایلی است که آپلود کرده‌ای.** حدس نیست.

## گام ۲ — با مایکت مقایسه کن

در پنل مایکت صفحهٔ برنامه، «نام بسته» را بخوان و **حرف‌به‌حرف** مقایسه کن.

---

## ۶ دلیل رایج که تغییر اثر نکرده

### ۱) بزرگی و کوچکی حروف ⚠️ محتمل‌ترین
نام بسته به بزرگ و کوچک بودن حروف **حساس است**:

```
com.SMRx.pasur11   ≠   com.smrx.pasur11   ≠   com.Smrx.pasur11
```

اگر در مایکت `com.smrx.pasur11` تایپ کرده‌ای ولی APK `com.SMRx.pasur11`
است، مایکت آن را قبول نمی‌کند. حرف‌به‌حرف چک کن.

### ۲) `namespace` را عوض کرده‌ای به‌جای `applicationId`
در `build.gradle.kts (Module :app)` هر دو هستند. آنی که فروشگاه می‌بیند
`applicationId` است:

```kotlin
android {
    namespace = "com.SMRx.pasur11"           // ← این را دست نزن
    defaultConfig {
        applicationId = "com.SMRx.pasur11"   // ← این را عوض کن
```

### ۳) فایل اشتباه را ویرایش کرده‌ای
**دو تا** `build.gradle.kts` وجود دارد. آنی که کنارش نوشته
**`(Module :app)`** درست است، نه `(Project: Pasur11)`.

### ۴) بعد از تغییر، Sync یا Rebuild نکرده‌ای
`Ctrl+S` ← دکمهٔ **Sync Now** ← بعد
**`Build`** ← **`Clean Project`** ← بعد دوباره APK امضاشده بساز.

### ۵) فایل قدیمی را آپلود کرده‌ای
مسیر خروجی `app/release/app-release.apk` است. اگر بیلد **خطا داده باشد**،
فایل قبلی همان‌جا می‌ماند و تو ناخواسته همان قدیمی را آپلود می‌کنی.
تاریخ فایل را نگاه کن — باید همین چند دقیقهٔ پیش باشد.

بعضی وقت‌ها هم خروجی اینجاست:
`app/build/outputs/apk/release/app-release.apk`

### ۶) در مایکت روی برنامهٔ اشتباه آپلود می‌کنی
اگر بیشتر از یک برنامه در پنل مایکت ساخته‌ای، مطمئن شو داخل همان برنامه‌ای
هستی که کالاهای `coins_*` را داخلش ساخته‌ای.

---

## هنوز درست نشد؟

این دو تصویر را بفرست تا دقیق بگویم:

1. پنجرهٔ **`Analyze APK`** (که نام بستهٔ واقعی APK را نشان می‌دهد)
2. صفحهٔ برنامه در **پنل مایکت** (که نام بستهٔ ثبت‌شده را نشان می‌دهد)

و اگر ممکن بود، متن کامل `build.gradle.kts (Module :app)`.

# جدول تصمیم — با دو عدد، جواب قطعی

نام بستهٔ APK تو: **`com.SMRx.pasur11`** (از پنجرهٔ Analyze APK خوانده شد)

حالا فقط کافی است ببینی مایکت چه چیزی ثبت کرده:

| مایکت چه می‌گوید | کاری که باید بکنی |
|---|---|
| `com.smahdi2razavi.pasur11` | در `build.gradle.kts (Module :app)` بنویس: `applicationId = "com.smahdi2razavi.pasur11"` — `namespace` را دست نزن |
| `com.SMRx.pasur11` (کاملاً یکسان) | نام بسته مشکلی ندارد؛ حتماً داری `app-debug.apk` یا فایل قدیمی را آپلود می‌کنی. `Build` ← `Clean Project` ← دوباره **Generate Signed APK** |
| `com.smrx.pasur11` (حروف کوچک) | یا در مایکت درستش کن، یا `applicationId = "com.smrx.pasur11"` بگذار |
| هر چیز دیگر | همان را دقیقاً در `applicationId` بگذار |

## فایل درست برای آپلود کدام است؟

فقط و فقط این:

```
app/release/app-release.apk
```

که با **`Build` ← `Generate Signed App Bundle / APK...`** ساخته می‌شود.

این‌ها را آپلود **نکن**:
- ❌ `app-debug.apk`
- ❌ هر فایلی داخل `app/build/intermediates/`
- ❌ فایل `.aab` (اگر مایکت APK خواسته)
