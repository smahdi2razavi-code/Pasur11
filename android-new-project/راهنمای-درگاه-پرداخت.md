# وصل‌کردن درگاه پرداخت مایکت (۰ تا ۱۰۰)

این روش از کتابخانهٔ رسمی مایکت استفاده می‌کند و **خیلی ساده است**: نه فایل AIDL
می‌خواهد، نه `onActivityResult`. فقط چند خط تنظیم + یک فایل کد.

سمت بازی (HTML) از قبل آماده است؛ فقط تکهٔ اندروید را وصل می‌کنیم.

---

## گام ۱ — مخزن jitpack را اضافه کن
فایل **`settings.gradle.kts`** (در ریشهٔ پروژه، نه داخل app) را باز کن. بخش
`dependencyResolutionManagement { repositories { ... } }` را پیدا کن و داخل
`repositories` این خط را اضافه کن:
```kotlin
maven { url = uri("https://jitpack.io") }
```
باید کنار `google()` و `mavenCentral()` قرار بگیرد.

---

## گام ۲ — کتابخانهٔ پرداخت را اضافه کن
فایل **`build.gradle.kts` (:app)** → داخل `dependencies { ... }` این خط را اضافه کن:
```kotlin
implementation("com.github.myketstore:myket-billing-client:1.19")
```
`Ctrl+S` → دکمهٔ **Sync Now** بالا را بزن و صبر کن.

---

## گام ۳ — دسترسی پرداخت را اضافه کن
فایل **`AndroidManifest.xml`** → کل محتوایش را با فایل
**`AndroidManifest-با-پرداخت.xml`** (از همین پوشه) جایگزین کن. این فقط یک خط
دسترسی پرداخت به مانیفست قبلی اضافه می‌کند. `Ctrl+S`.

---

## گام ۴ — کد MainActivity با پرداخت
فایل `MainActivity.kt` را باز کن → کل محتوایش را پاک کن → محتوای فایل
**`MainActivity-با-پرداخت.kt`** (از همین پوشه) را بگذار. `Ctrl+S`.
- کلید عمومی درگاه تو از قبل داخل کد گذاشته شده.
- اگر زیر `import ir.myket...` خط قرمز ماند، یعنی Sync گام ۲ کامل نشده.

---

## گام ۵ — ساخت شناسه‌ها (SKU) در پنل مایکت
وارد پنل توسعه‌دهندهٔ مایکت شو و در بخش «خرید درون‌برنامه‌ای» این چهار محصول را با
**دقیقاً همین شناسه‌ها** بساز (نوع همه: محصول معمولی / Consumable):

| شناسه (SKU) | چه می‌دهد | قیمت پیشنهادی |
|-------------|-----------|----------------|
| `coins_500`  | ۵۰۰ سکه | دلخواه |
| `coins_1500` | ۱۵۰۰ سکه | دلخواه |
| `coins_4000` | ۴۰۰۰ سکه | دلخواه |
| `vip_subscription` | فعال‌سازی VIP | دلخواه |

> اسم‌ها باید مو‌به‌مو یکی باشند وگرنه خرید کار نمی‌کند. کلید عمومی (RSA) را هم از
> همین پنل بردار و مطمئن شو با کلیدی که در `MainActivity` هست یکی است.

---

## گام ۶ — ساخت APK امضاشده و آزمایش
1. `Build` → `Generate Signed Bundle / APK` → `APK` → کلید امضا بساز/انتخاب کن.
2. APK را در پنل مایکت آپلود کن.
3. خرید درون‌برنامه‌ای **فقط روی نسخهٔ نصب‌شده از مایکت** کار می‌کند (نه در تست
   معمولی). بعد از انتشار/آزمایش مایکتی، یک خرید بزن و مطمئن شو سکه‌ها اضافه می‌شوند.

---

## چطور کار می‌کند (پشت صحنه)
- کاربر روی «خرید» می‌زند → بازی `AndroidBilling.buy("coins_500")` را صدا می‌زند.
- اپ صفحهٔ پرداخت مایکت را باز می‌کند.
- بعد از پرداخت موفق، اپ خودکار `grantPurchase("coins_500")` (یا `grantVip()`) را در
  بازی صدا می‌زند و سکه/‌VIP اضافه می‌شود. سکه‌ها «مصرف» می‌شوند تا دوباره قابل خرید باشند.

## اگر گیر کردی
عکس خطا را بفرست. مخصوصاً اگر بعد از Sync خط قرمز ماند یا هنگام خرید پیام خطا دیدی.
