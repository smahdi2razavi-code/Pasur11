# ربات تلگرام مدیریت کاربران پاسور ۱۱

با این ربات می‌توانی کاربران را با «شناسهٔ کاربری» (همان `۱۱-XXXXXX` که در پروفایل
هر کاربر هست) مدیریت کنی: مشاهده، مسدودسازی، هدیهٔ سکه و فعال‌سازی VIP.

## ⚠ پیش‌نیاز مهم: Firebase
ربات و بازی باید یک **دیتابیس مشترک (Firebase Realtime Database)** داشته باشند.
این هنوز راه‌اندازی نشده. تا وقتی Firebase وصل نشود، ربات نمی‌تواند به بازی وصل شود.
(راه‌اندازی Firebase همان چیزی است که بازی دو نفره و جدول جهانی را هم فعال می‌کند.)

---

## چطور کار می‌کند (نقشهٔ کلی)
1. بازی (بعد از اتصال Firebase) اطلاعات هر کاربر را زیر `/users/<شناسه>` می‌نویسد.
2. تو در تلگرام به ربات دستور می‌دهی (مثلاً `/coins 11-123456 500`).
3. ربات دستور را زیر `/control/<شناسه>` در Firebase ذخیره می‌کند.
4. بازی دفعهٔ بعد که باز شود، آن دستور را می‌خواند و اعمال می‌کند (سکه اضافه می‌شود،
   VIP فعال می‌شود، یا اگر مسدود شده باشد پیام می‌دهد و اجازهٔ بازی نمی‌دهد).

---

## راه‌اندازی ربات
1. **ساخت ربات:** در تلگرام به `@BotFather` پیام بده → `/newbot` → یک نام و یوزرنیم
   بده → **توکن** را بگیر.
2. **آی‌دی عددی خودت:** به `@userinfobot` پیام بده تا آی‌دی عددی‌ات را بدهد (برای ADMIN_IDS).
3. **فایل کلید سرویس Firebase:** در کنسول Firebase → Project Settings → Service accounts
   → «Generate new private key» → فایل `serviceAccountKey.json` را کنار `bot.py` بگذار.
4. در `bot.py` چهار مقدار بالای فایل را پر کن: `BOT_TOKEN`، `ADMIN_IDS`،
   `DATABASE_URL`، `SERVICE_ACCOUNT`.
5. نصب کتابخانه‌ها و اجرا:
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```
6. ربات باید ۲۴ ساعته روشن بماند (روی کامپیوتر شخصی، یک سرور، یا سرویس رایگان مثل
   Railway / Render / PythonAnywhere).

## دستورهای ربات
- `/user 11-123456` — نمایش اطلاعات و وضعیت کاربر
- `/users` — فهرست ۲۰ کاربر آخر
- `/ban 11-123456` — مسدودکردن
- `/unban 11-123456` — رفع مسدودی
- `/coins 11-123456 500` — هدیهٔ ۵۰۰ سکه
- `/vip 11-123456` — فعال‌کردن VIP

## تکهٔ سمت بازی (بعد از راه‌اندازی Firebase اضافه می‌شود)
این کد را من بعد از وصل‌کردن Firebase در بازی می‌گذارم (الان اضافه نشده تا بازی
بدون‌باگ بماند). فقط برای اطلاع تو:

```js
// بعد از تنظیم FIREBASE_DB_URL: همگام‌سازی کاربر و اعمال دستورهای مدیریتی
async function syncUserWithServer(){
  if(!firebaseConfigured()) return;
  const uid = ensureUserId();
  // ۱) ثبت/به‌روزرسانی اطلاعات کاربر
  fetch(FIREBASE_DB_URL+'/users/'+uid+'.json',{method:'PUT',body:JSON.stringify({
    name:SET.pName, user:SET.profileUsername||'', level:PROG.level,
    coins:PROG.coins, trophies:PROG.trophies, ts:Date.now()
  })}).catch(()=>{});
  // ۲) خواندن و اعمال دستورهای مدیریتی
  try{
    const r = await fetch(FIREBASE_DB_URL+'/control/'+uid+'.json');
    const c = await r.json();
    if(c){
      if(c.banned){ /* نمایش پیام مسدودی و بستن بازی */ }
      if(c.coinGrant){ addCoins(c.coinGrant);
        fetch(FIREBASE_DB_URL+'/control/'+uid+'/coinGrant.json',{method:'PUT',body:'0'}); }
      if(c.vipGrant){ grantVip();
        fetch(FIREBASE_DB_URL+'/control/'+uid+'/vipGrant.json',{method:'PUT',body:'false'}); }
    }
  }catch(e){}
}
```

## جمع‌بندی
ربات آماده است، ولی برای کار کردن باید اول **Firebase** راه‌اندازی شود. هر وقت
بخواهی، Firebase را قدم‌به‌قدم می‌سازیم؛ این کار هم‌زمان ربات مدیریت، بازی دو نفرهٔ
آنلاین و جدول رتبه‌بندی جهانی را فعال می‌کند.
