# پاسور ۱۱

بازی کلاسیک ورق ایرانی — وب، PWA و اپلیکیشن اندروید (مایکت).

---

## 🟢 برای باز کردن در اندروید استودیو

**پوشهٔ `androidapp` را باز کنید، نه این پوشه.**

```
File  →  Open  →  androidapp  →  OK
```

اگر این پوشهٔ بیرونی را باز کنید، اندروید استودیو پروژه را پیدا نمی‌کند و
فقط فایل‌ها را نشان می‌دهد.

راهنمای کامل: [`androidapp/README.md`](androidapp/README.md)

---

## این مخزن چه دارد

| پوشه / فایل | چیست |
|---|---|
| `index.html` | **خودِ بازی** — همه‌چیز در همین یک فایل است |
| `manifest.json` · `sw.js` · `icon-*.png` | فایل‌های لازم برای نسخهٔ وب و نصب روی گوشی (PWA) |
| `androidapp/` | **پروژهٔ آمادهٔ اندروید استودیو** — همین را باز کنید |
| `server/` | سرور بازی (Node.js) برای اجرا روی سرور خودتان |
| `LICENSES.md` | مجوز منابعی که در بازی استفاده شده |

---

## کارهای رایج

### تغییر دادن بازی
فایل `index.html` را ویرایش کنید. بعد همان فایل را در این مسیر هم کپی کنید
تا اپلیکیشن هم به‌روز شود:

```
androidapp/app/src/main/assets/game/index.html
```

> هر بار که نسخهٔ تازه‌ای منتشر می‌کنید، این سه عدد باید با هم بخوانند:
> - `APP_VERSION_CODE` و `APP_VERSION_NAME` داخل `index.html`
> - `versionCode` و `versionName` در `androidapp/app/build.gradle.kts`

### راه‌اندازی سرور
