# راه‌اندازی سرور پاسور ۱۱ روی پارس‌پک — ۰ تا ۱۰۰

کد سرور (`server.js`) **هیچ وابستگی بیرونی ندارد** و روی هر میزبانی اجرا می‌شود.
این راهنما مخصوص پارس‌پک است.

---

## ⚠ نکتهٔ حیاتی: سرور حتماً باید HTTPS داشته باشد

بازی تو داخل اپ با آدرس امن (`https://`) اجرا می‌شود. مرورگر اندروید **اجازه نمی‌دهد**
یک صفحهٔ امن به سرور غیرامن (`http://`) وصل شود. پس:

> ❌ `http://185.xx.xx.xx:3000` → کار **نمی‌کند**
> ✅ `https://api.yourdomain.ir` → کار می‌کند

یعنی به یک **دامنه + گواهی SSL** نیاز داری. در روش الف این خودکار است.

# روش الف (پیشنهادی) — هاست ابری Node.js پارس‌پک

ساده‌ترین راه، بدون نیاز به دانش سرور. HTTPS خودکار داده می‌شود.

## گام ۱ — خرید سرویس
1. برو به: https://parspack.com/paas/nodejs
2. سرویس **هاست ابری Node.js** را بگیر (کوچک‌ترین پلن کافی است).

## گام ۲ — ساخت برنامه
1. وارد پنل پارس‌پک شو → بخش سرویس‌های ابری → **ایجاد برنامهٔ جدید**.
2. **نوع:** `Node.js` — نسخهٔ `18` یا بالاتر.
3. یک نام بگذار، مثلاً `pasur11`.

## گام ۳ — آپلود کد
سه فایل زیر را از پوشهٔ `server` این پروژه آپلود کن (یا از طریق Git وصل کن):
- `server.js`
- `package.json`
- `liara.json` را **لازم نداری** (مخصوص لیاراست).

پارس‌پک با دیدن `package.json` خودش `npm start` را اجرا می‌کند.

## گام ۴ — متغیرهای محیطی
در تنظیمات برنامه، این‌ها را اضافه کن:

| نام | مقدار |
|---|---|
| `ADMIN_KEY` | یک رمز قوی بساز (مثلاً `Pasur11_x9K2mQ7z`) و جای امن نگه دار |
| `DATA_FILE` | `/app/data/data.json` (یا مسیر دیسک دائمی که پنل می‌دهد) |

> `ADMIN_KEY` جلوی سوءاستفاده را می‌گیرد؛ بدون آن کسی نمی‌تواند به کاربران سکه یا VIP بدهد.

## گام ۵ — دیسک دائمی (مهم)
اگر پنل گزینهٔ **«دیسک/فضای ذخیره‌سازی دائمی»** دارد، یکی بساز و مسیرش را
`/app/data` بگذار؛ وگرنه با هر بار استقرار مجدد، جدول رتبه‌بندی پاک می‌شود.

## گام ۶ — تست
آدرسی که پنل می‌دهد (مثلاً `https://pasur11.parspack.app`) را با `/health` باز کن:
```
https://pasur11.parspack.app/health
```
اگر `{"ok":true,...}` دیدی، سرور سالم است ✅

## گام ۷ — وصل‌کردن بازی
در `index.html` این خط را پیدا کن و آدرس سرورت را بگذار:
```js
const FIREBASE_DB_URL='https://pasur11.parspack.app';
```
سپس فایل را در `app/src/main/assets` جایگزین کن → `Build → Clean Project` → **Run**.

# روش ب — سرور مجازی (VPS) لینوکس پارس‌پک

اگر VPS گرفتی، مراحل بیشتر است ولی کنترل کامل داری. **به یک دامنه نیاز داری.**

## گام ۱ — خرید و اتصال
1. یک **VPS لینوکس (اوبونتو ۲۲.۰۴)** از https://parspack.com/vps/linux بگیر.
2. با SSH وصل شو (از کامپیوترت):
```bash
ssh root@آی‌پی‌سرور
```

## گام ۲ — نصب Node.js
```bash
apt update && apt upgrade -y
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
node -v          # باید v20.x نشان دهد
```

## گام ۳ — قرار دادن کد سرور
```bash
mkdir -p /opt/pasur11 && cd /opt/pasur11
```
حالا فایل‌های `server.js` و `package.json` را در این پوشه بگذار (با WinSCP، FileZilla
یا دستور `nano server.js` و کپی‌کردن محتوا).

## گام ۴ — اجرای دائمی با pm2
```bash
npm install -g pm2
cd /opt/pasur11
ADMIN_KEY="رمز_قوی_تو" DATA_FILE="/opt/pasur11/data.json" PORT=3000 pm2 start server.js --name pasur11
pm2 save
pm2 startup        # دستوری که می‌دهد را کپی و اجرا کن تا بعد از ریستارت هم بالا بیاید
```
تست محلی:
```bash
curl http://127.0.0.1:3000/health
```

## گام ۵ — دامنه
یک دامنه بگیر (مثلاً از خود پارس‌پک) و یک رکورد **A** بساز:
```
api.yourdomain.ir  →  آی‌پی سرورت
```
چند دقیقه صبر کن تا اعمال شود.

## گام ۶ — Nginx + گواهی SSL رایگان
```bash
apt install -y nginx certbot python3-certbot-nginx

cat >/etc/nginx/sites-available/pasur11 <<'EOF'
server {
    listen 80;
    server_name api.yourdomain.ir;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
EOF

ln -s /etc/nginx/sites-available/pasur11 /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx

# گواهی SSL رایگان (دامنه را با مال خودت عوض کن)
certbot --nginx -d api.yourdomain.ir
```
Certbot خودش HTTPS را فعال و تمدید خودکار می‌کند.

## گام ۷ — فایروال
```bash
ufw allow OpenSSH
ufw allow 'Nginx Full'
ufw --force enable
```

## گام ۸ — تست و اتصال بازی
در مرورگر: `https://api.yourdomain.ir/health` → باید `{"ok":true,...}` بدهد.
بعد در `index.html`:
```js
const FIREBASE_DB_URL='https://api.yourdomain.ir';
```

```bash
cd /opt/pasur11

pm2 restart pasur11
```
