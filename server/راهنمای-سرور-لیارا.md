# راه‌اندازی سرور پاسور ۱۱ روی لیارا — ۰ تا ۱۰۰

چون Firebase (گوگل) از داخل ایران بدون VPN کار نمی‌کند، سرور را روی **لیارا**
(میزبان ایرانی) راه می‌اندازیم تا همهٔ کاربران ایرانی بدون VPN بازی کنند.

این سرور همهٔ کارهای Firebase را انجام می‌دهد:
- ✅ اتصال بازی دو نفره (کد کوتاه ۷ رقمی)
- ✅ جدول رتبه‌بندی جهانی
- ✅ یکتایی نام‌کاربری
- ✅ مدیریت کاربران برای ربات تلگرام (سکه، VIP، مسدودسازی)

> نکته: کد سرور کامل تست شده است (۱۲ آزمون موفق) و به هیچ دیتابیس بیرونی نیاز ندارد.

---

## گام ۱ — ساخت حساب لیارا
1. برو به https://liara.ir و ثبت‌نام کن (با شمارهٔ ایرانی).
2. وارد **کنسول لیارا** شو.

## گام ۲ — ساخت برنامه
1. در کنسول، **«ایجاد برنامه»** را بزن.
2. **پلتفرم:** `Node.js`
3. **نام برنامه:** مثلاً `pasur11` (این در آدرس نهایی می‌آید: `pasur11.liara.run`)
4. **پلن:** کوچک‌ترین/رایگان کافی است.
5. برنامه را بساز.

## گام ۳ — نصب ابزار خط فرمان لیارا
روی کامپیوترت (اگر Node.js نداری، اول از nodejs.org نصب کن):
```bash
npm install -g @liara/cli
liara login
```

## گام ۴ — تنظیم کلید مدیریت (مهم برای امنیت)
در کنسول لیارا → برنامه‌ات → بخش **«متغیرهای محیطی» (Environment Variables)**
این دو را اضافه کن:

| نام | مقدار |
|---|---|
| `ADMIN_KEY` | یک رمز دلخواه و قوی بساز (مثلاً `Pasur11_x9K2mQ7z`) — این را جای امن نگه دار |
| `DATA_FILE` | `/var/lib/data/data.json` |

> `ADMIN_KEY` جلوی سوءاستفاده را می‌گیرد: بدون آن کسی نمی‌تواند به کاربران سکه
> بدهد یا VIP فعال کند. فقط ربات تلگرام تو این کلید را دارد.

## گام ۵ — ساخت دیسک (برای اینکه داده‌ها پاک نشوند)
در کنسول لیارا → برنامه‌ات → بخش **«دیسک‌ها»** → یک دیسک با نام `data` بساز و
مسیر اتصالش را `/var/lib/data` بگذار.

> اگر این کار را نکنی، با هر بار استقرار دوباره، جدول رتبه‌بندی پاک می‌شود.

## گام ۶ — استقرار (Deploy)
در ترمینال، وارد پوشهٔ `server` این پروژه شو و بزن:
```bash
cd server
liara deploy --app pasur11 --platform node --port 3000
```
صبر کن تا بالا بیاید. در پایان آدرس برنامه‌ات را می‌دهد، مثلاً:
```
https://pasur11.liara.run
```

## گام ۷ — تست سرور
در مرورگر این آدرس را باز کن:
```
https://pasur11.liara.run/health
```
اگر چیزی شبیه `{"ok":true,"name":"pasur11-server",...}` دیدی، سرور سالم است ✅

## گام ۸ — وصل‌کردن بازی به سرور جدید
در فایل `index.html` این خط را پیدا کن:
```js
const FIREBASE_DB_URL='https://pasur-11-default-rtdb.asia-southeast1.firebasedatabase.app';
```
و آدرس سرور خودت را جایش بگذار:
```js
const FIREBASE_DB_URL='https://pasur11.liara.run';
```
سپس `index.html` را در `app/src/main/assets` جایگزین کن → `Build → Clean Project` → **Run**.

حالا بازی بدون VPN و با IP ایران کامل کار می‌کند 🎉

---

## وصل‌کردن ربات تلگرام به این سرور
ربات قبلی برای Firebase نوشته شده بود. با این سرور، ربات باید از همین آدرس
استفاده کند. فایل `telegram-bot/bot_liara.py` برای همین آماده شده — فقط سه مقدار
بالای فایل را پر کن:
- `BOT_TOKEN` (از @BotFather)
- `ADMIN_IDS` (آی‌دی عددی خودت از @userinfobot)
- `SERVER_URL` و `ADMIN_KEY` (همان‌هایی که در گام ۴ و ۶ ساختی)

---

## هزینه
پلن پایهٔ لیارا برای این سرور بسیار ارزان (و در شروع رایگان) است، چون سرور فقط
پیام‌های کوچک رد و بدل می‌کند — خودِ بازی دو نفره مستقیم بین دو گوشی انجام می‌شود.

## اگر گیر کردی
خروجی خطای `liara deploy` یا صفحهٔ `/health` را برایم بفرست.
