# پروژهٔ آمادهٔ اندروید — پاسور ۱۱

این پوشه یک **پروژهٔ کامل و آمادهٔ اندروید استودیو** است. هیچ فایلی را لازم
نیست کپی یا ویرایش کنید — فقط بازش کنید و دکمهٔ اجرا را بزنید.

---

## کاری که باید بکنید (۴ قدم)

### ۱. دانلود

روی گیت‌هاب دکمهٔ سبز **Code** → **Download ZIP** را بزنید (حتماً وقتی شاخهٔ
`claude/screen-server-gateway-issues-0jyp6m` انتخاب شده باشد)، یا این آدرس را
مستقیم در مرورگر باز کنید:

```
https://github.com/smahdi2razavi-code/Pasur11/archive/refs/heads/claude/screen-server-gateway-issues-0jyp6m.zip
```

فایل زیپ را جایی باز کنید (مثلاً روی Desktop).

### ۲. باز کردن در اندروید استودیو

اندروید استودیو → منوی **File** → **Open** → پوشهٔ **`androidapp`** را انتخاب
کنید (نه پوشهٔ بیرونی، دقیقاً `androidapp`) → **OK**

> ⏳ بار اول ۵ تا ۱۵ دقیقه طول می‌کشد تا اندروید استودیو کتابخانه‌ها را دانلود
> کند. پایین صفحه که نوشت **Gradle sync finished** یعنی آماده است.

### ۳. وصل کردن گوشی

1. در گوشی: **تنظیمات** → **دربارهٔ گوشی** → ۷ بار روی **شمارهٔ ساخت** بزنید
2. **تنظیمات** → **گزینه‌های توسعه‌دهنده** → **اشکال‌زدایی USB** را روشن کنید
3. گوشی را با کابل به کامپیوتر وصل کنید و روی گوشی **اجازه** را بزنید

### ۴. اجرا

دکمهٔ سبز ▶ بالای اندروید استودیو را بزنید. بازی روی گوشی باز می‌شود.

---

## تست خرید

1. **مایکت** را روی همان گوشی نصب کنید و وارد حسابتان شوید
2. در بازی → **فروشگاه** → روی **خرید** بزنید
3. پنجرهٔ پرداخت مایکت باید باز شود

> خرید واقعی فقط با همان امضایی کار می‌کند که در مایکت ثبت کرده‌اید. برای
> تست بدون پرداخت پول، در پنل مایکت بخش «تست خرید» حساب خودتان را اضافه کنید.

---

## ساختن فایل نهایی برای مایکت

1. منوی **Build** → **Generate Signed App Bundle / APK** → **APK** → Next
2. بار اول: **Create new…** را بزنید و یک فایل کلید (keystore) بسازید
3. **release** را انتخاب کنید → Finish
4. فایل ساخته‌شده: `androidapp/app/release/app-release.apk`

> 🔴 **فایل کلید و رمزش را جای امن نگه دارید.** اگر گم شود، دیگر هرگز
> نمی‌توانید برای همین برنامه در مایکت آپدیت بدهید.

## اگر چیزی را خواستید عوض کنید

| چه چیزی | کجا |
|---|---|
| نام برنامه | `app/src/main/res/values/strings.xml` |
| آیکون برنامه | فایل‌های `ic_launcher.png` در پوشه‌های `res/mipmap-*` |
| آدرس سرور بازی | داخل `app/src/main/assets/game/index.html` → خط `DEFAULT_API_BASE` |
| به‌روزرسانی خودکار | `app/src/main/java/ir/smrx/pasur11/MainActivity.kt` → خط `UPDATE_URL` |
| نام بسته (package) | باید با پنل مایکت یکی باشد: `ir.smrx.pasur11` |

### به‌روزرسانی خودکار بازی

الان `UPDATE_URL` خالی است، یعنی بازی فقط از داخل خود برنامه اجرا می‌شود.
این برای انتشار در مایکت کاملاً درست کار می‌کند.

اگر بعداً بخواهید بدون دادن نسخهٔ جدید به مایکت، بازی را به‌روز کنید، آدرس
`index.html` روی سایتتان را در `UPDATE_URL` بگذارید. از آن به بعد کاربران
خودکار نسخهٔ جدید را می‌گیرند.

> برنامه فقط نسخه‌ای را قبول می‌کند که شمارهٔ `game-version` در `index.html`
> آن **بزرگ‌تر** از نسخهٔ فعلی باشد. پس هر بار بازی را تغییر دادید، عدد
> `<meta name="game-version" content="2">` را یکی بالا ببرید.

## خطاهای رایج

| خطا | راه‌حل |
|---|---|
| `SDK location not found` | اندروید استودیو خودش می‌سازدش؛ اگر نساخت: File → Project Structure → SDK Location |
| `Failed to resolve: com.github.farasource` | اینترنت به `jitpack.io` وصل نمی‌شود |
| Gradle sync گیر کرد | اینترنت آزاد لازم است؛ اندروید استودیو کتابخانه‌ها را از اینترنت می‌گیرد |
| صفحهٔ سفید موقع اجرا | نباید پیش بیاید؛ اگر شد، تب **Logcat** پایین اندروید استودیو را بفرستید |
| دکمهٔ خرید کار نمی‌کند | مایکت روی گوشی نصب است؟ نام بسته با پنل مایکت یکی است؟ |

اگر خطایی گرفتید، **متن کامل خطا** را از تب **Build** یا **Logcat** کپی کنید
و بفرستید.
