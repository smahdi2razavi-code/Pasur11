# مجوز منابع شخص ثالث

آیکون‌های برداری داخل `index.html` (بخش `<svg id="iconSprite">`) از دو مجموعهٔ
متن‌باز زیر گرفته شده‌اند. هر دو با مجوز **MIT** منتشر شده‌اند و طبق شرط این
مجوز، متن حق نشرشان در ادامه آمده است.

## مجموعه‌هایی که بررسی شدند ولی استفاده نشدند

| مخزن | دلیل |
|---|---|
| [threejsassets/game-hud](https://github.com/threejsassets/game-hud) | MIT است، ولی برای بازی‌های اکشن (نوار جان، مینی‌مپ، هات‌بار) طراحی شده و برای بازی ورق کاربردی ندارد. فقط از ایدهٔ نشانگر نوبت و نوار درخشان آن الهام گرفته شد؛ هیچ کدی از آن کپی نشده است. |
| [joangeldelarosa/pxlkit](https://github.com/joangeldelarosa/pxlkit) | مجوز تفکیکی دارد و آیکون‌هایش شرایط تجاری جداگانه‌ای دارند؛ ضمناً برای React نوشته شده و این بازی جاوااسکریپت خالص است. |
| [CoherentLabs/Gameface-UI](https://github.com/CoherentLabs/Gameface-UI) | بر پایهٔ SolidJS و مخصوص موتور Coherent Gameface است و با این پروژه سازگار نیست. |
