# ساخت اپلیکیشن اندروید پاسور ۱۱ — راهنمای قدم‌به‌قدم

این راهنما برای کسی نوشته شده که **هیچ چیز از برنامه‌نویسی نمی‌داند**.
هر قدم را دقیقاً همان‌طور که نوشته شده انجام دهید. جایی که نوشته «کپی کنید»،
یعنی محتوای فایل را کامل انتخاب کنید و به‌جای محتوای قبلی بچسبانید.

**زمان لازم:** حدود ۴۵ دقیقه برای بار اول.

---

## چیزی که در نهایت خواهید داشت

یک اپلیکیشن اندروید که:
- بازی را نشان می‌دهد و **بدون اینترنت هم کار می‌کند**
- در پس‌زمینه آخرین نسخهٔ بازی را می‌گیرد، پس برای هر تغییر کوچک **لازم نیست نسخهٔ جدید به مایکت بدهید**
- دکمه‌های خرید سکه و اشتراک VIP را به **درگاه مایکت** وصل می‌کند

---

## قدم ۰ — چیزهایی که لازم دارید

| چیز | توضیح |
|---|---|
| اندروید استودیو | از `developer.android.com/studio` دانلود و نصب کنید (حدود ۱ گیگابایت) |
| اینترنت | بار اول اندروید استودیو کلی فایل دانلود می‌کند |
| حساب مایکت | همان که محصولات را در آن ثبت کرده‌اید |

> ⚠️ اندروید استودیو برای دانلود فایل‌هایش به اینترنت بدون محدودیت نیاز دارد.
> اگر دانلودها گیر کرد، این موضوع را در نظر داشته باشید.

---

## قدم ۱ — ساختن پروژهٔ خالی

1. اندروید استودیو را باز کنید
2. روی **New Project** بزنید
3. از لیست، **Empty Views Activity** را انتخاب کنید (نه Empty Activity، نه Compose) → **Next**
4. این فیلدها را دقیقاً این‌طور پر کنید:

| فیلد | مقدار |
|---|---|
| Name | `Pasur11` |
| Package name | `ir.smrx.pasur11` |
| Save location | هرجا که دوست دارید |
| Language | **Kotlin** |
| Minimum SDK | **API 21 (Android 5.0)** |
| Build configuration language | **Kotlin DSL (build.gradle.kts)** |

5. **Finish** را بزنید و صبر کنید تا پایین صفحه نوشتهٔ «Gradle sync finished» بیاید
   (بار اول ممکن است ۵ تا ۱۵ دقیقه طول بکشد)

> ⚠️ **Package name را حتماً `ir.smrx.pasur11` بگذارید.** این همان نامی است که
> در پنل مایکت ثبت می‌شود و بعداً قابل تغییر نیست. اگر در پنل مایکت نام دیگری
> ثبت کرده‌اید، همان را بنویسید و در همهٔ فایل‌های زیر هم عوضش کنید.

---

## قدم ۲ — گذاشتن بازی داخل برنامه

بازی باید داخل اپلیکیشن قرار بگیرد تا بدون اینترنت هم بالا بیاید.

1. در ستون سمت چپ اندروید استودیو، بالای لیست فایل‌ها یک منوی کشویی هست که
   نوشته **Android**. روی آن بزنید و **Project** را انتخاب کنید.
2. این مسیر را باز کنید: `Pasur11` → `app` → `src` → `main`
3. روی پوشهٔ `main` **راست‌کلیک** کنید → **New** → **Directory** → اسمش را
   `assets` بگذارید → Enter
4. روی `assets` راست‌کلیک کنید → **New** → **Directory** → اسمش را `game` بگذارید
5. حالا این ۵ فایل را از مخزن گیت‌هاب بازی دانلود کنید و **داخل پوشهٔ `game`**
   بریزید (با کشیدن و رها کردن یا کپی/پیست در همان پنجرهٔ اندروید استودیو):

```
index.html
manifest.json
icon-192.png
icon-512.png
sw.js
```

> این فایل‌ها در `https://github.com/smahdi2razavi-code/Pasur11` هستند.
> ساده‌ترین راه: روی گیت‌هاب دکمهٔ سبز **Code** → **Download ZIP** را بزنید،
> فایل زیپ را باز کنید و این ۵ فایل را بردارید.

مسیر نهایی باید این‌طور باشد:
```
app/src/main/assets/game/index.html
app/src/main/assets/game/manifest.json
app/src/main/assets/game/icon-192.png
app/src/main/assets/game/icon-512.png
app/src/main/assets/game/sw.js
```

## قدم ۳ — اضافه کردن کتابخانهٔ خرید

دو فایل تنظیمات باید عوض شوند.

### ۳-الف) فایل `settings.gradle.kts`

در ستون چپ، در ریشهٔ پروژه فایلی به اسم **`settings.gradle.kts`** هست.
بازش کنید. داخلش دنبال این بخش بگردید:

```kotlin
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
    }
}
```

و **یک خط** به آن اضافه کنید تا این‌طور شود:

```kotlin
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven(url = "https://jitpack.io")
    }
}
```

فایل کامل نمونه در `android/gradle/settings.gradle.kts` همین مخزن است.

### ۳-ب) فایل `app/build.gradle.kts`

⚠️ **دقت کنید:** دو فایل به اسم `build.gradle.kts` وجود دارد. آن که **داخل
پوشهٔ `app`** است را باز کنید، نه آن که در ریشه است.

محتوای فایل `android/gradle/app-build.gradle.kts` از همین مخزن را **کامل کپی
کنید و به‌جای کل محتوای فایل بچسبانید.**

بعد از چسباندن، بالای پنجره یک نوار زرد ظاهر می‌شود با دکمهٔ **Sync Now**.
رویش بزنید و صبر کنید تا تمام شود.

> اگر خطای `Failed to resolve: com.github.farasource` گرفتید، یعنی قدم ۳-الف
> را انجام نداده‌اید یا اینترنت به jitpack.io وصل نمی‌شود.

## قدم ۴ — کپی کردن دو فایل کد

1. در ستون چپ این مسیر را باز کنید:
   `app` → `src` → `main` → `java` → `ir` → `smrx` → `pasur11`
2. فایل **`MainActivity.kt`** آنجاست. بازش کنید، **همهٔ محتوایش را پاک کنید**،
   و محتوای `android/kotlin/MainActivity.kt` از این مخزن را بچسبانید.
3. روی پوشهٔ `pasur11` راست‌کلیک کنید → **New** → **Kotlin Class/File** →
   اسمش را `MyketBridge` بگذارید و **File** را انتخاب کنید → Enter
4. محتوای `android/kotlin/MyketBridge.kt` از این مخزن را داخلش بچسبانید.

> اگر Package name شما `ir.smrx.pasur11` نیست، خط اول هر دو فایل
> (`package ir.smrx.pasur11`) را با نام خودتان عوض کنید.

---

## قدم ۵ — تنظیم فایل AndroidManifest.xml

مسیر: `app` → `src` → `main` → **`AndroidManifest.xml`**

محتوای `android/manifest/AndroidManifest.xml` از این مخزن را کامل جایگزین کنید.

بعد این خط را در همان فایل پیدا کنید:
```xml
android:theme="@style/Theme.Pasur11"
```
اگر اندروید استودیو زیرش خط قرمز کشید، اسم تم پروژهٔ خودتان را بگذارید.
اسم درست را از فایل `app/src/main/res/values/themes.xml` پیدا می‌کنید
(معمولاً چیزی شبیه `@style/Theme.Pasur11` یا `@style/AppTheme` است).

---

## قدم ۶ — تنظیم ProGuard (مهم برای نسخهٔ نهایی)

مسیر: `app` → **`proguard-rules.pro`**

محتوای `android/layout/proguard-rules.pro` از این مخزن را **به انتهای** فایل
اضافه کنید.

> بدون این کار، نسخهٔ نهایی (release) که به مایکت می‌دهید ممکن است دکمهٔ خرید
> در آن کار نکند، در حالی که روی گوشی خودتان درست بود. این یکی از رایج‌ترین
> اشتباه‌هاست.

---

## قدم ۷ — آدرس به‌روزرسانی

فایل `MainActivity.kt` را باز کنید و این خط را پیدا کنید:

```kotlin
private const val UPDATE_URL = "https://smahdi2razavi-code.github.io/Pasur11/index.html"
```

- اگر بازی را روی **GitHub Pages** گذاشته‌اید: همین را بگذارید بماند
- اگر روی **سرور پارس‌پک** خودتان گذاشته‌اید: آدرس خودتان را بنویسید
- اگر اصلاً نمی‌خواهید به‌روزرسانی خودکار داشته باشید: `""` بگذارید (دو کوتیشن خالی)

---

## قدم ۸ — اجرا و تست

1. گوشی اندرویدی را با کابل به کامپیوتر وصل کنید
2. در گوشی: **تنظیمات** → **دربارهٔ گوشی** → روی **شمارهٔ ساخت** ۷ بار بزنید
   تا حالت توسعه‌دهنده فعال شود
3. در **تنظیمات** → **گزینه‌های توسعه‌دهنده** → **اشکال‌زدایی USB** را روشن کنید
4. در اندروید استودیو بالای صفحه اسم گوشی‌تان باید ظاهر شود
5. دکمهٔ سبز ▶ (Run) را بزنید

**بازی باید روی گوشی باز شود.**

### تست خرید

1. **مایکت را روی همان گوشی نصب کنید** و با حساب خودتان وارد شوید
2. در بازی به **فروشگاه** بروید و روی **خرید** بزنید
3. پنجرهٔ پرداخت مایکت باید باز شود

> ⚠️ خرید واقعی فقط وقتی کار می‌کند که برنامه با **همان امضایی** ساخته شده
> باشد که در مایکت ثبت کرده‌اید. برای تست، در پنل مایکت بخش «تست خرید» حساب
> خودتان را اضافه کنید تا پول واقعی کم نشود.

---

## قدم ۹ — ساختن فایل نهایی برای مایکت

1. منوی **Build** → **Generate Signed App Bundle / APK**
2. **APK** را انتخاب کنید → Next
3. اگر اولین بار است: **Create new…** را بزنید و یک فایل کلید (keystore) بسازید

> 🔴 **این فایل کلید و رمزش را جای امن نگه دارید و هیچ‌وقت گم نکنید.**
> اگر گم شود، دیگر هرگز نمی‌توانید برای همین برنامه در مایکت آپدیت بدهید و
> مجبورید برنامه را از صفر با نام جدید منتشر کنید.

4. **release** را انتخاب کنید → Finish
5. فایل ساخته‌شده در این مسیر است:
   `app/release/app-release.apk`
6. همین فایل را در پنل مایکت آپلود کنید

## چیزهایی که باید بدانید

### آدرس سرور بازی
اگر سرور پارس‌پک را راه انداخته‌اید، **قبل از** قدم ۲ این خط را در `index.html`
پر کنید (راهنمای کامل در `server/README.md`):

```js
const DEFAULT_API_BASE='';        // ← آدرس سرور اینجا
```

بدون آن، جدول رتبه‌بندی جهانی و کد ۷ رقمی بازی دو نفره کار نمی‌کند، ولی
**خرید و بقیهٔ بازی کاملاً درست کار می‌کند** (خرید را خود مایکت روی گوشی تأیید
می‌کند).

### اگر کاربر برنامه را پاک و دوباره نصب کند
سکه و اشتراک VIP او **برنمی‌گردد**. دلیلش این است که هر شش محصول شما در پنل
مایکت «محصول یک‌بارمصرف» هستند و باید بعد از خرید مصرف شوند تا کاربر بتواند
دوباره بخرد (وگرنه هر کسی فقط یک بار در عمرش می‌توانست VIP بخرد).

راه حل این مشکل، فعال کردن **ورود با حساب گوگل** است تا پیشرفت کاربر به حسابش
گره بخورد نه به گوشی‌اش. کد آن در بازی هست ولی تنظیم نشده. اگر خواستید، بگویید
تا کاملش کنم.

### وقتی بازی را تغییر دادید
اگر `UPDATE_URL` را پر گذاشته‌اید، فقط کافی است `index.html` جدید را روی
گیت‌هاب یا سرورتان بگذارید. کاربرها دفعهٔ بعد که بازی را باز کنند نسخهٔ جدید را
می‌گیرند و **لازم نیست نسخهٔ جدید به مایکت بدهید**.

فقط وقتی باید APK جدید بسازید که خودِ کد اندروید عوض شود.

## خطاهای رایج

| خطا | چه کار کنم |
|---|---|
| `Failed to resolve: com.github.farasource` | قدم ۳-الف را انجام نداده‌اید (خط jitpack) |
| `Unresolved reference: WebViewAssetLoader` | خط `androidx.webkit` در `app/build.gradle.kts` نیست، یا Sync نکرده‌اید |
| `Unresolved reference: MyketBridge` | فایل `MyketBridge.kt` را نساخته‌اید یا در پوشهٔ اشتباه است |
| صفحهٔ سفید موقع اجرا | فایل‌های بازی در مسیر `assets/game/` نیستند |
| `@style/Theme.Pasur11 not found` | قدم ۵، بخش تم را بخوانید |
| دکمهٔ خرید کار نمی‌کند | مایکت روی گوشی نصب است؟ شناسه‌های محصول با پنل یکی است؟ |
| در نسخهٔ release خرید کار نمی‌کند ولی در debug کار می‌کرد | قدم ۶ (ProGuard) را انجام نداده‌اید |

---

## کجا گیر کردید؟

اگر خطایی گرفتید، **متن کامل خطا** را برایم بفرستید (از پایین اندروید استودیو،
تب **Build** یا **Logcat**). با متن خطا می‌توانم دقیقاً بگویم چه کار کنید.
